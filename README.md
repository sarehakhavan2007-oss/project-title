 معرفی پروژه

این پروژه یک **شبیه‌ساز جام جهانی فوتبال** با رویکرد  ۳۲ تیمی است که با استفاده از **برنامه‌نویسی شی‌گرا** در پایتون پیاده‌سازی شده است.

هدف اصلی این پروژه، پیش‌بینی شانس قهرمانی تیم‌های مختلف بر اساس قدرت واقعی آنها (امتیاز حمله، دفاع و رنکینگ فیفا) است. این برنامه با اجرای هزاران بار شبیه‌سازی از کل تورنمنت، درصد قهرمانی هر تیم را محاسبه و گزارش می‌دهد.

---

ازارها و کتابخانه‌های استفاده‌شده

| کتابخانه | کاربرد |
|:---|:---|
| **random** | شبیه‌سازی تصادفی و قرعه‌کشی گروه‌ها |
| **csv** | خواندن فایل تیم‌ها از CSV |
| **os** | بررسی وجود فایل (اختیاری) |
| **math** | محاسبات ریاضی (اختیاری) |
| **numpy** | استفاده از توزیع پواسون برای شبیه‌سازی گل (توصیه شده) |
| **matplotlib** | رسم نمودار درصد قهرمانی (اختیاری + نمره اضافه) |

> **توضیح استفاده از numpy:**  
> از کتابخانه `numpy` برای پیاده‌سازی توزیع پواسون استفاده شده است. این توزیع، تعداد گل‌های هر تیم را به صورت واقع‌گرایانه‌تر از تصادف ساده شبیه‌سازی می‌کند و سرعت اجرای شبیه‌سازی‌های هزارباره را به طور چشمگیری افزایش می‌دهد.
